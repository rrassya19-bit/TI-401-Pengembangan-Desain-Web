# Pertemuan 7 — Mini Project Design & Pengantar Teknologi Web Modern

**Integratif Sub-CPMK51.1–51.5** — Mahasiswa mampu merancang UI/UX website secara utuh.
**Pengantar konseptual untuk CPMK54** — literasi AI generatif & Web 3.0 sebelum praktik hands-on.

## Isi
- `index.html` — kerangka landing page yang menggabungkan semua yang dipelajari pertemuan 1-6 (HTML semantik, form, CSS custom, Bootstrap grid & component). Ini jadi starting point Mini Project.
- `konsep-ai-web3.md` — materi literasi (bukan kode) tentang evolusi web, AI generatif/LLM, dan blockchain/wallet/smart contract secara konseptual. Dibaca/didiskusikan di kelas, bukan dipraktikkan.

## Tugas Praktikum yang disarankan
1. Kembangkan `index.html` menjadi landing page produk/organisasi pilihan kelompok (ganti konten, tambah section, sesuaikan warna).
2. Diskusikan 3 pertanyaan di akhir `konsep-ai-web3.md` secara berkelompok — ini fondasi untuk pertemuan 12 dan 14.
