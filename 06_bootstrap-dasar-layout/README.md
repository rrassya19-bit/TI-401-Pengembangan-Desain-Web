# Pertemuan 6 — Bootstrap Dasar & Layout

**Sub-CPMK 51.5** — Mahasiswa mampu merancang layout responsif menggunakan Bootstrap.

## Isi
- `index.html` — navbar responsif, grid 12-kolom (`container` > `row` > `col-*`), dan komponen `card`. Semua via CDN, tidak perlu install apa pun.

## Cara menjalankan
Buka `index.html` di browser (butuh koneksi internet untuk memuat Bootstrap dari CDN).

## Tugas Praktikum yang disarankan
1. Ubah jumlah kolom grid dari 3 menjadi 4 (`col-md-3`), amati bagaimana Bootstrap menyesuaikan.
2. Resize browser ke lebar HP — perhatikan navbar berubah jadi menu hamburger, dan grid menumpuk vertikal.
3. File ini akan jadi kerangka dasar Mini Project pertemuan 7.
