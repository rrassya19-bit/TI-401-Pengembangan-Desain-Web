# Pertemuan 10 — JavaScript OOP

**Sub-CPMK 52.2** — Mahasiswa mampu menerapkan konsep Object Oriented Programming dalam JavaScript untuk membangun struktur aplikasi yang modular.

## Isi
`script.js` mencakup:
1. `class` & `constructor` (`Produk`)
2. `inheritance` dengan `extends`/`super` (`ProdukDiskon`)
3. `encapsulation` dasar dengan private field `#` (`Akun`)
4. Array of objects + `forEach` — pola yang nanti dipakai lagi untuk menampilkan data ke DOM (pertemuan 11).

## Tugas Praktikum yang disarankan
1. Buat class baru `Mahasiswa` dengan method `hitungIPK(daftarNilai)`.
2. Buat class turunan `MahasiswaBerprestasi extends Mahasiswa` yang menambah properti `beasiswa`.
