# Pertemuan 1 — HTML Dasar

**Sub-CPMK 51.1** — Mahasiswa mampu menyusun struktur dokumen HTML yang benar dan semantik.

## Isi
- `index.html` — contoh halaman "Portal Berita Kampus" memakai tag semantik: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.

## Cara menjalankan
Buka langsung `index.html` di browser (tidak perlu server).

## Tugas Praktikum yang disarankan
1. Ganti isi menjadi profil pribadi/portofolio mahasiswa (tetap pakai tag semantik yang sama).
2. Tambahkan minimal 1 gambar (`<img>`) dan 1 tautan eksternal (`<a target="_blank">`).
3. Validasi HTML di https://validator.w3.org/ — pastikan 0 error (ini juga dipakai lagi di Sub-CPMK53.1 pertemuan 15).
