# Pertemuan 8 — Ujian Tengah Semester (UTS)

**Evaluasi CPMK51** — Mahasiswa menunjukkan kemampuan merancang solusi web berbasis kebutuhan.

Tidak ada kode praktikum di sesi ini — sesi ini adalah **ujian**, bukan praktikum.

## Cakupan Materi UTS
Mengacu ke Sub-CPMK51.1–51.5 (pertemuan 1–7):
- HTML semantik & struktur dokumen
- HTML Form & atribut validasi
- CSS dasar (selector, box model)
- CSS Layout (Flexbox & Grid)
- Bootstrap dasar & grid system

## Format yang disarankan
- Ujian praktik: membangun 1 halaman web statis + form dari studi kasus/brief yang diberikan, dikerjakan dari nol menggunakan HTML + CSS + Bootstrap.
- Rubrik penilaian mengacu ke Tabel Bobot Penilaian CPMK51 pada RPS (25% dari total nilai CPL 5).
- Folder `01` s.d. `07` pada rundown ini bisa dipakai sebagai bahan referensi/latihan sebelum UTS, bukan untuk dikerjakan ulang saat ujian.
