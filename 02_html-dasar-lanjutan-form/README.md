# Pertemuan 2 — HTML Dasar Lanjutan & HTML Form

**Sub-CPMK 51.1 (lanjutan) & 51.2** — Mahasiswa mampu membangun halaman web statis dan form input sesuai kebutuhan pengguna.

## Isi
- `index.html` — form pendaftaran seminar memakai elemen: `input` (text, email, radio, checkbox), `select`, `textarea`, `label`, `button`.

Catatan: validasi (required, pattern, dll.) sengaja **belum** ditambahkan di sini — itu materi pertemuan 3.

## Tugas Praktikum yang disarankan
1. Tambahkan minimal 2 field baru sesuai kebutuhan form kalian sendiri (mis. tanggal lahir dengan `type="date"`, nomor HP dengan `type="tel"`).
2. Pastikan setiap `input` punya `label` yang terhubung lewat `for`/`id` (aspek usability, bagian dari Sub-CPMK51.2).
