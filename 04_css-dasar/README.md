# Pertemuan 4 — CSS Dasar

**Sub-CPMK 51.3** — Mahasiswa mampu menerapkan styling dasar (warna, font, selector, box model).

## Isi
- `style.css` dikomentari per bagian: element selector, id selector, class selector, pseudo-class, attribute selector, dan box model (content/padding/border/margin).

## Tugas Praktikum yang disarankan
1. Ubah `.box` menjadi kartu profil (foto + nama + deskripsi singkat) memakai box model yang sudah dipelajari.
2. Tambahkan minimal 1 pseudo-class baru (`:first-child`, `:nth-child`, atau `:focus`) pada elemen pilihan kalian.
