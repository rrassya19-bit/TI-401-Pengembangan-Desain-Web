# Pertemuan 9 — JavaScript Dasar

**Sub-CPMK 52.1** — Mahasiswa mampu mengimplementasikan logika program dasar dalam JavaScript.

## Isi
- `script.js` mencakup: variabel (`let`/`const`), tipe data, operator, percabangan (`if/else`), perulangan (`for`), fungsi (declaration & arrow function).
- Ada 1 contoh interaktif kecil: kalkulator nilai akhir yang terhubung ke `index.html` (pengenalan sangat awal ke event handling, akan dibahas mendalam di pertemuan 11).

## Cara menjalankan
Buka `index.html`, lalu buka Console browser (F12 → tab Console) untuk melihat hasil `console.log`.

## Tugas Praktikum yang disarankan
1. Ubah bobot penilaian (30/30/40) sesuai skema penilaian mata kuliah lain yang kalian ambil.
2. Tambahkan fungsi baru: `konversiKeIPK(nilaiHuruf)` yang mengembalikan angka IPK (A=4, B=3, dst).
