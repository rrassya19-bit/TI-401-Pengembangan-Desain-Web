# Pertemuan 15 — Testing, Debugging, Evaluasi Kritis & Refactoring

**Sub-CPMK 53.1–53.6** — menutup siklus design → implement → evaluate untuk seluruh materi (termasuk AI API & Web 3.0).

## Isi
- `debug-examples.js` — teknik debugging dasar: `console.table`, `console.group`, `debugger`, bug klasik (`==` vs `===`, lupa `return`), pola try/catch untuk kode async.
- `checklist-pengujian.md` — checklist pengujian lengkap dari HTML sampai evaluasi kritis AI/Web3, dipakai untuk menguji hasil folder `01` s.d. `14`.
- `refleksi-kritis-template.md` — template tertulis untuk Sub-CPMK53.6, dipakai sebagai bagian asesmen CPMK53 (lihat Tabel Bobot Penilaian di RPS).

## Cara pakai di kelas
1. Mahasiswa menjalankan checklist di atas terhadap Mini Project (pertemuan 7) yang sudah dikembangkan sampai pertemuan 14.
2. Mahasiswa mengisi template refleksi kritis berdasarkan pengujian nyata terhadap fitur AI API dan Web3 mereka sendiri.
3. Dosen bisa memakai `debug-examples.js` sebagai bahan live-coding sesi debugging bersama.
