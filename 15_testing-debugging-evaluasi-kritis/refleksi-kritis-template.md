# Template Refleksi Kritis — Sub-CPMK53.6

Diisi mahasiswa sebagai bagian dari asesmen CPMK53 (lihat Tabel Bobot Penilaian RPS).
Tulis jawaban singkat (3-5 kalimat per poin) berdasarkan pengalaman memakai
fitur AI API (pertemuan 12) dan Web 3.0 front-end (pertemuan 14) pada project kalian.

## Bagian A — Evaluasi Kritis AI API
1. Berikan 1 contoh pertanyaan yang kalian ajukan ke chatbot, dan jawabannya.
2. Menurut kalian, apakah jawaban tersebut akurat? Bagaimana cara kalian memverifikasinya?
3. Apakah kalian menemukan indikasi *hallucination* atau bias dalam jawaban AI? Jelaskan.
4. Sebutkan 1 risiko kalau fitur AI ini dipakai di aplikasi produksi tanpa disclaimer ke pengguna.

## Bagian B — Evaluasi Kritis Web 3.0
5. Apa perbedaan pengalaman pengguna (UX) antara login biasa (email/password) dengan "connect wallet"?
6. Sebutkan 1 potensi risiko keamanan yang perlu diwaspadai pengguna saat memakai fitur wallet, dan bagaimana aplikasi kalian mengurangi risiko tersebut (mis. lewat pesan peringatan).

## Bagian C — Kesimpulan
