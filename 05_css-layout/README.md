# Pertemuan 5 — CSS Layout (Flexbox & Grid)

**Sub-CPMK 51.4** — Mahasiswa mampu merancang layout menggunakan Flexbox dan Grid.

## Isi
Tiga demo progresif dalam satu file:
1. Flexbox untuk navbar (horizontal, `justify-content`, `align-items`).
2. Flexbox untuk baris kartu responsif (`flex-wrap`, `flex: grow shrink basis`).
3. CSS Grid untuk layout dashboard (`grid-template-areas`) — pola yang sama akan dipakai ulang di Bootstrap grid pertemuan 6.

## Tugas Praktikum yang disarankan
1. Ubah `.dashboard` grid menjadi layout halaman utuh untuk mini project kalian di pertemuan 7.
2. Coba ubah lebar browser (resize) — amati kapan `.card-row` pindah baris karena `flex-wrap`.
