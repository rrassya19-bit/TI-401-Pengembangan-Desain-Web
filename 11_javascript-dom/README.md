# Pertemuan 11 — JavaScript DOM

**Sub-CPMK 52.3** — Mahasiswa mampu memanipulasi elemen halaman menggunakan JavaScript DOM untuk menciptakan interaktivitas.

## Isi
Aplikasi To-Do List sederhana (tanpa data tersimpan permanen) yang mendemonstrasikan:
- Seleksi elemen (`getElementById`, `querySelector`)
- Event handling (`addEventListener` untuk `click` dan `keydown`)
- Membuat & menghapus elemen dinamis (`createElement`, `appendChild`, `innerHTML`, `classList`)
- Pola *render function* (menggambar ulang tampilan dari data) — pola ini akan lebih terstruktur lagi setelah belajar modules di pertemuan 13.

## Tugas Praktikum yang disarankan
1. Tambahkan fitur "Edit tugas" (klik ganda pada teks untuk mengubahnya).
2. Tambahkan filter: tampilkan hanya tugas yang belum selesai.
